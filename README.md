Учебный и исследовательский проект по **планированию траекторий в робототехнике (Motion / Path Planning)**. В репозитории реализована продвинутая версия алгоритма **RRT (Rapidly-exploring Random Tree)**, объединяющая ключевые преимущества и эвристики из семейства современных RRT-алгоритмов: **RRT\***, **Bi-RRT (RRT-Connect)**, **Informed RRT\***, адаптивный шаг и сглаживание траектории.

Поддерживается работа в **2D и 3D пространствах**, анимация роста деревьев в реальном времени, а также интерактивный режим с возможностью **рисовать произвольные препятствия вручную**.

## 🚀 Ключевые алгоритмические особенности

В проекте реализован класс `RRTPlus`, который объединяет следующие модификации классического алгоритма:

```text
                            ┌─────────────────────────────────┐
                            │      Start & Goal Points        │
                            └────────────────┬────────────────┘
                                             │
                       ┌─────────────────────┴─────────────────────┐
                       ▼                                           ▼
             [Tree A (from Start)]                       [Tree B (from Goal)]
                       │                                           │
                       └───────────────► Bi-RRT ◄──────────────────┘
                                             │
             ┌───────────────────────────────┼───────────────────────────────┐
             ▼                               ▼                               ▼
     [Adaptive Step Size]            [RRT* Rewiring]             [Informed Ellipse]
   Шаг зависит от дистанции     Выбор оптимального родителя     После первого пути
     до ближайших препятствий       и перелинковка соседей        сэмплирование только
   (крупные шаги в пустом поле)    в динамическом радиусе r        внутри эллипса c_best
             │                               │                               │
             └───────────────────────────────┼───────────────────────────────┘
                                             │
                                   [Connection & Path]
                                             │
                                             ▼
                                  [Randomized Shortcut]
                               (Сглаживание и срез углов)
```

1. **Двунаправленный поиск (Bidirectional RRT-Connect)**:
   - Растут одновременно два дерева: от стартовой точки (`Tree_A`) и от целевой (`Tree_B`).
   - На каждом шаге деревья меняются ролями, пытаясь соединиться навстречу друг другу. Это на порядки сокращает время поиска пути по сравнению с классическим однонаправленным RRT.

2. **Оптимизация стоимости пути (RRT\*)**:
   - **Best Parent Selection**: при добавлении новой вершины алгоритм ищет лучшего родителя среди соседей в радиусе `r = min(r_search * √(ln(n) / n), 3 * max_step)`, минимизируя суммарную длину пути от корня.
   - **Tree Rewiring**: проверяется, не станет ли путь до соседних вершин короче, если направить их через новую вершину. При улучшении стоимости дерево динамически перелинковывается с каскадным пересчётом стоимости поддеревьев (`update_costs`).

3. **Адаптивный шаг (Adaptive Step Size)**:
   - Длина шага приращения вершины (`steer`) динамически вычисляется через расстояние до ближайшего препятствия:
     ```text
     step = clip(0.8 * dist_obstacle, min_step, max_step)
     ```
   - На открытых пространствах алгоритм делает широкие шаги, ускоряя исследование карты, а в узких коридорах и около препятствий — аккуратные микрошаги.

4. **Информированное эллиптическое сэмплирование (Informed RRT\*)**:
   - Как только найден первый допустимый путь длиной `c_best`, алгоритм прекращает равномерное сэмплирование по всей карте.
   - Новые случайные точки генерируются строго внутри **фокального гиперэллипсоида (эллипса в 2D)** с фокусами в точках `Start` и `Goal` и большой полуосью `a = c_best / 2`.
   - Любая точка вне этого эллипса заведомо не может улучшить текущий путь, поэтому её отсечение даёт быструю сходимость к теоретически оптимальной траектории.

5. **Сглаживание пути (Randomized Path Smoothing / Shortcut)**:
   - Постобработка найденного пути случайными хордами: алгоритм выбирает случайные не соседние вершины пути и проверяет отрезок между ними на коллизии.
   - Если препятствий нет, промежуточные избыточные изломы удаляются (`shortcut`), делая траекторию плавной и реалистичной для роботов.

6. **2D и 3D планирование**:
   - Векторная математика на `numpy` прозрачно работает как для плоскости `(X, Y)`, так и для трёхмерного пространства `(X, Y, Z)` со сферическими препятствиями.

## 🎮 Режимы работы (`main.py`)

Запустив скрипт `python main.py`, вы увидите интерактивное консольное меню с 4 режимами:

```text
===========================================
 ULTIMATE RRT ALGORITHM SUITE (ALL-IN-ONE)
 (Bidirectional, Informed, Adaptive, Smoothed)
===========================================
1. Static 2D Example
2. Static 3D Example (Fast Rendering)
3. Interactive 2D (Click Start/Goal)
4. Custom Draw 2D (Draw Obstacles)
5. Exit
```

### 1. Static 2D Example
- Запуск алгоритма на классической тестовой 2D-сцене с круглыми препятствиями.
- Визуализация в реальном времени:
  - **Синее дерево** — рост от старта (`Tree_A`).
  - **Оранжевое дерево** — рост от финиша (`Tree_B`).
  - **Малиновая линия** — момент соединения деревьев.
  - **Фиолетовый пунктирный эллипс** — визуализация области Informed RRT\*, которая сужается по мере оптимизации длины пути.
  - **Зеленая линия** — лучший найденный путь RRT\*.
  - **Золотая толстая линия** — итоговый сглаженный путь.

### 2. Static 3D Example (Fast Rendering)
- Трёхмерное планирование траектории в кубической рабочей зоне с 3D-сферами.
- Оптимизированный рендеринг: пространственные деревья рисуются через быстрый batch-буфер координат, предотвращая просадки FPS в Matplotlib 3D.

### 3. Interactive 2D (Click Start/Goal)
- Пользователь выбирает начальную и конечную точку кликами мыши на готовой карте:
  1. Первый клик левой кнопкой мыши — **Start** (синий крестик).
  2. Второй клик левой кнопкой мыши — **Goal** (красный крестик).
- Алгоритм автоматически рассчитывает и отрисовывает оптимальный маршрут.

### 4. Custom Draw 2D (Draw Obstacles)
- Режим свободного рисования препятствий:
  - Зажмите левую кнопку мыши и рисуйте стены, тупики, лабиринты и препятствия произвольной формы.
  - Нажмите интерактивную кнопку **«RUN ULTIMATE RRT»** внизу экрана.
  - Алгоритм в реальном времени найдёт выход из нарисованного лабиринта с учётом безопасного клиренса робота (`clearance`).

## 📊 Математика и алгоритмы

### Отрезок к точке (Collision Detection)
Для препятствий, нарисованных пользователем, используется проекция точки $p$ на отрезок траектории $ab$:

$$
t = \text{clamp}\left(\frac{(\mathbf{p} - \mathbf{a}) \cdot (\mathbf{b} - \mathbf{a})}{\|\mathbf{b} - \mathbf{a}\|^2}, 0, 1\right)
$$

$$
\text{dist}(\mathbf{p}, \mathbf{ab}) = \|\mathbf{p} - (\mathbf{a} + t(\mathbf{b} - \mathbf{a}))\|
$$

### Сэмплирование эллипса (Informed RRT*)
Полуоси фокального эллипса вычисляются через текущую лучшую стоимость $c_{\text{best}}$ и теоретический минимум $c_{\text{min}} = \|\mathbf{x}_{\text{start}} - \mathbf{x}_{\text{goal}}\|$:

$$
r_1 = \frac{c_{\text{best}}}{2}, \quad r_2 = \frac{\sqrt{|c_{\text{best}}^2 - c_{\text{min}}^2|}}{2}
$$

Точка внутри единичного круга поворачивается на угол наклона прямой между стартом и целью:

$$
\theta = \text{atan2}(y_{\text{goal}} - y_{\text{start}}, x_{\text{goal}} - x_{\text{start}})
$$
